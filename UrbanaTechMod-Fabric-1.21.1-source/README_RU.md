# Urbana Tech & Needs — Fabric 1.21.1

Это **исходный проект-прототип**, а не готовый `.jar`. Включены:
- предметы-блоки: унитаз, Wi‑Fi-роутер, телевизор, компьютер и ИИ дата-центр;
- предметы RAM и пульт;
- HUD с двумя полосами нужд: «Писать» и «Какать»;
- интеракции с блоками и русские названия.

## Что пока не реализовано
- Сейчас полосы нужд — клиентский прототип: унитаз пока не синхронизирует их сброс между сервером и клиентом.
- Интернет как проверяемая сеть, размещение роутеров/станций, установка RAM и ИИ-чат — ещё не реализованы.
- Видео YouTube внутри игры не встроено. Для настоящего встроенного видео нужен отдельный медиаплеер/библиотека и согласование лицензий; открытие ссылки во внешнем браузере — более простой следующий этап.
- Браузер Google и запуск полноценных игр из Minecraft не включены.

## Сборка
1. Установи JDK 21.
2. Установи Gradle 8.x или добавь Gradle Wrapper.
3. В папке проекта выполни `gradle build`.
4. Готовый мод, если сборка успешна, будет в `build/libs/urbana-tech-1.0.0.jar`.
5. Установи Fabric Loader для Minecraft 1.21.1 и Fabric API той же версии; скопируй JAR в `.minecraft/mods`.

Если Gradle сообщит об ошибке API или версий, нужно исправить её под фактическую среду сборки. Этот архив здесь не компилировался, поэтому я не выдаю его за проверенный JAR.
